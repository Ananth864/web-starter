## Project structure

| Path                      | Purpose                                      |
| ------------------------- | -------------------------------------------- |
| `apps/web/src/routes`     | TanStack Start routes                        |
| `apps/web/content/docs`   | Documentation pages                          |
| `packages/ui`             | Shared shadcn components and Tailwind tokens |
| `apps/web/vite.config.ts` | Vite and Fumadocs MDX plugins                |
| `apps/web/alchemy.run.ts` | Cloudflare deployment and Worker bindings    |

## Environment

Local variables live in `apps/web/.env`. Start with `apps/web/.env.example` and follow the repository README for your selected backend and auth provider.

Keep secrets out of public `VITE_` variables.

## Verify changes

Run formatting, linting, and type checks from the repository root:

```bash
bun run check
```

Build the app after changing routing, authentication, deployment, or Vite configuration:

```bash
bun run build
```
